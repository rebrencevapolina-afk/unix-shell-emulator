# Эмулятор командной оболочки UNIX-подобной ОС

## Общее описание

Данный проект представляет собой эмулятор командной оболочки (shell) UNIX-подобной операционной системы, реализованный на языке Python. Приложение работает в режиме REPL (Read-Eval-Print Loop) и поддерживает базовые команды, имитирующие работу в командной строке.

**Вариант №27.**

## Функциональность

На текущем этапе (Этап 1) реализованы:

- Консольный интерфейс (CLI) с приглашением к вводу вида `VFS>`.
- Парсер командной строки, который:
  - разбивает ввод на команду и аргументы;
  - раскрывает переменные окружения реальной ОС (например, `$HOME`).
- Команды-заглушки:
  - `ls` — выводит свое имя и полученные аргументы;
  - `cd` — выводит свое имя и полученные аргументы.
- Команда `exit` — завершает работу эмулятора.
- Обработка ошибок: для неизвестных команд выводится сообщение `команда: command not found`.

## Требования

- Python версии 3.10 или выше.
- Операционная система: Windows, macOS или Linux.

## Команды для запуска

1. Убедитесь, что Python установлен: python --version
2. Запустите эмулятор:
python main.py

## Примеры использования

### Пример 1. Работа команды-заглушки `ls`
VFS> ls
ls


### Пример 2. Работа команды-заглушки `cd` с аргументом
VFS> cd /home/user
cd /home/user


### Пример 3. Раскрытие переменной окружения `$HOME`
VFS> ls $HOME
ls /Users/username


### Пример 4. Обработка неизвестной команды
VFS> foo bar
foo: command not found


### Пример 5. Завершение работы
VFS> exit
Выход из эмулятора.
